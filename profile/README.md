# Synparc

**Supervision intelligente de parc informatique**

Croisez vos données Active Directory, Microsoft 365 et vos postes en temps réel.

[![Status](https://img.shields.io/badge/status-En%20développement-orange?style=flat-square)]()
[![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](LICENSE)

</div>

---

Synparc unifie en une seule interface les informations dispersées de votre environnement IT — annuaire, cloud, postes et serveurs — pour vous donner une vue claire et croisée de votre parc.

**Ce que Synparc fait :**

- Qui est connecté sur quel poste, croisé avec l'Active Directory
- Permissions réelles de chaque utilisateur sur vos ressources réseau et SharePoint
- État de santé de vos machines en temps réel et dans le temps
- Cohérence entre les rôles AD et les licences Microsoft 365
